Raw Rust bindings to Wireshark's `libwireshark` (EPAN). **The C declarations
ship with the crate, one bundle per Wireshark release line, so no Wireshark
SDK or source tree is needed**: only the installed Wireshark to link
against. For writing plugins, use
[`libwireshark`](https://crates.io/crates/libwireshark).

## Features

- Bindings for Wireshark 3.0 to 4.6, generated by bindgen at build time from
  the bundle matching the installed release line.
- Bundles for Windows, Linux, macOS and FreeBSD on x86_64 and aarch64.
- Links the runtime library directly; on Windows, builds the import library
  Wireshark's installer leaves out from the DLL's exports.
- Uses a development SDK instead when pkg-config or the `WIRESHARK_*`
  directory variables point at one.

## Installation

```console
cargo add libwireshark-sys
```

The build needs Clang/libclang (bindgen), and on Windows without an SDK,
`llvm-readobj` and `llvm-dlltool` on `PATH`.

## Quick start

```rust,ignore (links Wireshark)
let major = libwireshark_sys::VERSION_MAJOR;
```

Every declaration is `unsafe` C; see `libwireshark` for a safe API.

## API overview

One module of generated items, re-exported at the root: functions, types
and constants of the EPAN public headers, plus `VERSION_MAJOR`,
`VERSION_MINOR` and `VERSION_MICRO` of the release line bound.

## Finding Wireshark

1. An SDK: `WIRESHARK_DIR`, `WIRESHARK_INCLUDE_DIR`, `WIRESHARK_LIB_DIR`,
   `WIRESHARK_GENERATED_INCLUDE_DIR`, `WIRESHARK_SOURCE_DIR`, else pkg-config
   `wireshark`.
2. Else the runtime library: `WIRESHARK_DLL`, `WIRESHARK_DIR`, then the
   default install locations.
3. The release line comes from the SDK, the `tshark --version` beside the
   library, `WIRESHARK_VERSION`, or `WIRESHARK_TSHARK`.

`WIRESHARK_NO_LINK=1` with `WIRESHARK_VERSION=4.6` generates bindings without
linking (`cargo check`, docs). docs.rs builds the 4.6 bindings.

## Development

The bundles are generated by `cargo wireshark headers generate` and kept on
the repository's `headers` branch; a checkout's build reads them from there.
See the repository README.
